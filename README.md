# Inheritance in C++
This repository contains basic **C++** program based on **Inheritance** as an important concept in Onject-Oriented Programming (OOP).

## Purpose
 This repository is created for learning, implementing, understanding inheritance in C++.

### Concepts Covered
- Basic Inheritance
- Base and Derived Class
- Types of Inheritance
- Private, Protected, Public Data
- Code Reusability
